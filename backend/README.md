# ezchrono backend

Bun + Elysia API and scheduler. See the top-level [README](../README.md) for configuration and [DEVELOPER.md](../DEVELOPER.md) for the layout.

- `bun run dev` starts the server with watch mode.
- `bun test` runs the suite against an in-memory database and a local fake target.
- `bun run typecheck` runs `tsc` in strict mode.
